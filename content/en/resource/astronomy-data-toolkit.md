Curated tools for astronomy workflows: visualization, catalog inspection, and reproducible notebooks.

## Core Tools

- **Astropy**: core package for I/O, coordinates, and units
- **TOPCAT**: quick catalog inspection and cross-matching
- **Aladin Lite**: sky visualization in the browser
- **Jupyter + matplotlib**: reproducible exploration
