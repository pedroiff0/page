## 📋 Ementa

Árvores binárias de pesquisa. Árvores balanceadas e discussão de desempenho. Fila de prioridades. Pesquisa digital. Ordenação externa. Espalhamento. Implementação de estruturas de dados eficientes em disco.

## 🎯 Objetivos

- Aprimorar e estender os conceitos e técnicas vistos em Algoritmos e Estruturas de Dados 1, fazendo com que
- aluno tenha habilidade de resolver problemas computacionais de forma mais eficiente.

## 📖 Conteúdo Programático

1. Ordenação Externa

- Manipulação de arquivos

2. Tabela Hash

- Funções Hash
- Tratamento de Colisões
- Algoritmos para Tabelas Hash

3. Árvores Binárias

- Percurso em Árvores
- Árvores Binárias
- Árvores Binárias de Busca
- Operações de Árvores Binárias de Busca
- Balanceamento de Árvores
- Árvores AVL
- Inserção
- Remoção
- Busca
- Rebalanceamento
- Árvores B e B+
- Inserção
- Remoção
- Busca
- Rebalanceamento

4. Estruturas de Dados Eficientes em Disco
